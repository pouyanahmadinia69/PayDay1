# PayDay — مدیر هوشمند پول

وب‌اپ فارسی مدیریت درآمد، هزینه و اقساط (PWA). همه داده‌ها فقط روی گوشی خودتان ذخیره می‌شود.

## انتشار روی GitHub Pages
1. یک مخزن (repository) جدید بسازید و همه فایل‌ها را در ریشه آن آپلود کنید (بدون پوشه).
2. Settings ← Pages ← Source: `Deploy from a branch` ← شاخه `main` و پوشه `/ (root)`.
3. بعد از چند دقیقه آدرس `https://USERNAME.github.io/REPO/` فعال می‌شود.

## نصب روی آیفون
آدرس را در Safari باز کنید ← Share ← Add to Home Screen.

## نکات
- بعد از هر تغییر در `index.html`، عدد نسخه را در `sw.js` عوض کنید (`payday-v2` و ...).
- اعلان قسط فقط وقتی برنامه باز است نمایش داده می‌شود.
- پیامک بانکی باید کپی و در تب «پیامک» چسبانده شود.
